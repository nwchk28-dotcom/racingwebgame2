[全25コースの画像付きレポート](review.html) に、各コースのオンボード・特徴的な施設・全景を、PC 1280×720とスマホ相当844×390で保存しています。**計150画像**です。コース名のリンクから各セクションへ移動できます。

一覧画像：

- [特徴的な施設](landmarks-contact.jpg)
- [各コースの全景](overview-contact.jpg)
- [オンボード](onboard-contact.jpg)

一覧画像と各ビューを確認し、コースごとの施設形状・植生・地形の違い、観客席の方向、配置漏れを点検しました。モンツァはSafari上でも直接描画・再生を確認しています。資料の出典と近似した範囲は [CIRCUIT_SCENERY_REFERENCES.md](../../CIRCUIT_SCENERY_REFERENCES.md) を参照してください。

全25コースの樹木合計は **25,940本**（うちスパ2,700本）です。画像生成時の施設の配置漏れは0件でした。個別画像は `<course-id>/view-1.jpg`～`view-6.jpg` にあります。

画像を生成したSafariのブラウザ情報・各ビューの描画回数・三角形数・コース準備時間は [metrics.json](metrics.json) に保存しています。保存したオンボード画像では最大215 draw calls、最大534,502三角形でした（最大値はそれぞれ別のコース）。各コースのテクスチャ数は2です。

これは静止ビューの描画確認です。全コースを実機で継続走行したフレーム時間・温度・消費電力の検証ではありません。施設確認・全景だけ霧を外し、オンボードにはゲームと同じ霧を適用しています。iOS Simulatorは起動していません。

- その他22コース：0→1
